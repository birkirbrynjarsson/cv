# Birkir Brynjarsson — CV

Personal CV/resume website for Birkir Brynjarsson, available in Icelandic and English.

## Structure

```
index.html        # Icelandic version (default)
en/index.html     # English version
css/              # Stylesheets (Bootstrap, Font Awesome, custom)
js/               # Scripts (Bootstrap, jQuery, custom)
img/              # Images and PDF documents
fonts/            # Web fonts
```

## Tech Stack

- HTML5
- Bootstrap 3
- Font Awesome 5
- jQuery
- Custom CSS (`css/main.css`)

## Development

No build step required. Open `index.html` directly in a browser or serve with any static file server:

```bash
npx serve .
```

## Languages

- **Icelandic** — `index.html`
- **English** — `en/index.html`
